This directory contains sample website screenshots displayed on the main page showcase section.

2. **artisan-bakery.png**

   - Recommended size: 1920x1200px

3. **pawfect-grooming.png**
   - Screenshot of the PawfectGrooming website
   - Shows: "Your Pet's Perfect Grooming Experience" with golden retriever

## Screenshot Guidelines

- **Format**: PNG (preferred) or JPG
- **Dimensions**: 1920x1200px or similar 16:10 aspect ratio
- **Quality**: High resolution for crisp display
- **Content**: Capture the hero section and main navigation
- **File naming**: Use lowercase with hyphens (as shown above)

## Usage

These screenshots are displayed in the ShowcaseSection component on the main landing page (/app/page.tsx), allowing visitors to see real examples of AI-generated websites.
